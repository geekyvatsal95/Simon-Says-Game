# 🎮 Simon Says Game

<p align="center">
  A fun memory-based game built using <b>HTML, CSS, and JavaScript</b>
</p>

---

## 🚀 Live Demo
👉 <a href="https://geekyvatsal95.github.io/Simon-Says-Game/">Play Game</a>

---

## 🎯 Features
✨ Random color sequence generation  
📈 Level-based difficulty increase  
🎨 Interactive UI with animations  
❌ Game over feedback  

---

## 🕹️ How to Play
1️⃣ Press any key to start  
2️⃣ Watch the sequence carefully  
3️⃣ Repeat the same pattern  
4️⃣ Game ends on mistake
